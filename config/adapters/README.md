# LoRA Adapter Configurations & Training Summaries (`config/adapters/`)

This directory contains the committed PEFT LoRA configuration files (`adapter_config.json`) and training/evaluation summaries (`results.json`) for every fine-tuning run of **`nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16`** executed on Nebius AI Cloud spot H200 GPUs via SkyPilot.

## What is in GitHub (`config/adapters/`) vs. Hugging Face (`gretchenboria/nemofleet-ego-lora`)

| Artifact | Location | Why |
|---|---|---|
| **`adapter_config.json`** (`1.1 KB` each) | Committed here in `config/adapters/<run>/<adapter>/adapter_config.json` | Documents exact PEFT/LoRA hyperparameters (`r=16` / `r=32`, `lora_alpha`, `lora_dropout=0.05`, `peft_version="0.21.2"`, and `target_modules`: Mamba `in_proj`, attention `q/k/v/o_proj`, and MoE shared-expert `up_proj`/`down_proj`). |
| **`results.json`** (`1.4–5.9 KB` each) | Committed here in `config/adapters/<run>/results.json` | Records exact training steps, wall-clock seconds, throughput (`tokens_per_s`), GPU cost (`usd`), best validation loss, held-out `val` and `test` AUROC / recall@10%FAR, and 300-sample JSON generation metrics. |
| **`config/night_shift.json`** (`5.2 KB`) | Committed in `config/night_shift.json` (generated by `tools/night_shift/publish.py`) | Aggregated held-out evaluation tables, calibrated action-token probability gate levels, and the calibrated `in_way` logit threshold (`-0.75`) read by the live console and Cloudflare API. |
| **`adapter_model.safetensors`** (binary LoRA weights) | Stored in private Hugging Face model repo **`gretchenboria/nemofleet-ego-lora`** under matching `<run>/<adapter>/adapter_model.safetensors` paths | Kept out of git (`*.safetensors` in `.gitignore`) both for repository size hygiene and to comply with the **Waymo Dataset License Agreement for Non-Commercial Use** for runs that include Waymo Open Motion v1.3.1 vehicle-ego trajectories. |

When `tools/ego_mix/sky_serve.yaml` launches the dual-adapter spot H200 serving endpoint, it downloads `decide-1/adapter_decide_v1` and `plan-1/adapter_ego_mix_plan` directly from `gretchenboria/nemofleet-ego-lora` and mounts both adapters onto a single `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B-BF16` model via `tools/ego_mix/serve.py`.
